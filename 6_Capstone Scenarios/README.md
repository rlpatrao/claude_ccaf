# Capstone Scenarios

The exam presents scenario-based questions drawn from a set of practical scenarios (at the time of writing, six scenarios, of which four appear in a given exam; verify against the current exam guide). Each capstone below integrates labs from several domains into one working system that matches a scenario.

Attempt the capstones after completing Domains 1 to 5. For each one, write a short design note before building, then build it, then ask Claude to quiz you on that scenario.
