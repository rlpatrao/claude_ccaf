# Capstone: Code Generation with Claude Code

**Domains exercised:** 3 (Claude Code Configuration), 5 (Context and Reliability)

## Scenario

A team uses Claude Code to generate code, refactor, debug, and document. The configuration must give consistent results across developers and keep sessions effective on a large codebase.

## Build brief

Configure a real or sample repository so that a teammate cloning it receives the same conventions, commands, and skills.

**Components to integrate from earlier labs**

- Project CLAUDE.md with imports (3.1).
- Project commands and a forked skill (3.2).
- Path-specific rules for tests and API code (3.3).
- Plan mode for a multi-file change (3.4).
- Test-driven iteration (3.5).
- Scratchpad and `/compact` strategy for long sessions (5.4).

## Acceptance criteria

- [ ] A fresh clone gives a teammate identical project behaviour, with nothing team-wide in user-level files.
- [ ] One multi-file change was completed through plan mode with a recorded plan.
- [ ] Your notes explain each configuration choice in exam terms.
